# Пространство · Музей Арктики и Антарктики

Интерактивная рабочая реконструкция помещений для обсуждения будущей выставки.

**[Открыть 3D-модель](https://koclow.github.io/arctic-museum-space/)**

## Возможности

- План помещений № 48 и № 47 и расширенная версия по воспоминаниям Саши.
- Зеркальное отражение для сравнения гипотез о расположении.
- Вид сверху, осмотр изнутри, свод, размеры, существующая экспозиция.
- Сопоставление исходных фотографий и планов, пояснения к предположениям.

Это исследовательская модель по доступным материалам. Предположительные участки отмечены; точные размеры и расположение помещений требуют проверки по обмерам и документам музея.

## Запуск

Сайт состоит из статических файлов. Для локального просмотра выполните `python3 -m http.server 8000` в папке проекта и откройте `http://localhost:8000`.

GitHub Pages публикует корень ветки `main`. Для обновления замените `index.html`, `style.css`, `app.js` и папку `assets` новой сборкой.

Исходные фотографии и планы используются как материалы для сверки; ссылки на источники приведены внутри модели. Права на эти материалы принадлежат их авторам.
